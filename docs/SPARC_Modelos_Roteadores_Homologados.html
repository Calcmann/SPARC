ℹ️ Diretrizes Técnicas e Operacionais de Bancada e Campo

• Detecção Automática: O motor analítico do SPARC identifica o fabricante, arquitetura e estado operacional (Normal, ROMMON, BootWare, BIOS Halt ou Bloqueado por Senha) diretamente pela serial console.
• Staging LAN Dinâmico: Em roteadores Cisco, o SPARC aplica IP temporário via console para carga HTTP/TFTP de bancada, validando a interface antes para prevenir conflitos de sub-rede.
• Multiplataforma Nativa: Suporte completo no Windows (desktop/notebook na Base Claro) e no Android (smartphone/tablet via OTG no cliente), com os mesmos algoritmos de provisionamento.
• Aceite de Avisos Legais: O diálogo inicial pós-recuperação do FortiGate 40F (PRE WARNING) é aceito automaticamente com "a" sem intervenção manual do operador.
